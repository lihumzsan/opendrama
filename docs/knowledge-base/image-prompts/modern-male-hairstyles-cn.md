# 现代男主发型补充词库

## 收录原则

- 目标是补充现代男主发型结构，不直接复制公众号模板。
- 发型用于区分男主、男二、反派和群像角色，不能替代身份、服装和性格设定。
- 每个男主角色建议固定 1 个基础发型，只有换装、时间跨度或剧情转折时才调整。
- 参考图带水印，只用于理解发型轮廓，不进入项目素材。

## 短剧男主发型选择规则

- 休闲日常男主：优先法式碎盖、微分碎盖、短碎纹理，服装搭衬衫、针织衫、T 恤。
- 商务成熟男主：优先三七侧分、低渐层侧背、法式侧分、低渐层短背；正式宴会再用经典油头。
- 动作硬朗男主：优先美式前刺、寸头渐变、圆寸、利落平头；机车或极强个性才用莫西干短刺。
- 文艺温柔男主：优先中分层次、韩式中分、日系短碎；需要避免刘海遮住双眼。
- 街头潮流角色：优先狼尾短发、鲻鱼短发、锡纸烫短发；同剧只给少数强个性人物使用。
- 同一部短剧里不要把“碎盖系”给所有男主：男主碎盖，男二中分，反派侧背，动作角色寸头，区分会更清楚。

### 去重规则

- 法式碎盖、微分碎盖、短碎纹理同属“自然短碎发”，运行时只选一个名称。
- 韩式中分、中分层次、日系中分微卷同属“中分柔和发”，靠发长和卷度区分。
- 狼尾、鲻鱼、长碎后颈同属“后颈延伸发”，同剧不要给多名男性角色重复使用。
- 经典油头、港风背头、湿发背头同属“后梳露额发”，按场景决定光泽强弱。
- 美式前刺、飞机头、莫西干短刺同属“上扬短刺发”，动作角色优先美式前刺，极强个性才用莫西干。


## OpenDrama 用法

- 角色 bible：把男主发型作为独立字段记录，例如 `hairstyle: natural textured fringe, neat short sides`。
- 多男主区分：男主可以用商务三七分，男二用日系中分微卷，反派用复古侧分油头，街头角色用狼尾。
- 分镜连续性：同一集内默认保持基础发型一致；湿发、背头、挑染等只在换装、宴会、舞台或时间跨度明确时出现。
- H3 视频：首尾帧中发型只能有风吹、轻微晃动、湿润程度变化，不要发生寸头变狼尾这类结构突变。

## 风险

- 这篇主要是发型图库，不是完整男主人设；必须结合职业、服装、年龄和表情使用。
- 部分发型容易把角色推向同质化精修男团脸，应通过脸型、眉眼和服装场景继续区分。
- 潮发、挑染、湿发和光头都需要剧情理由，不适合作为默认美化标签。
