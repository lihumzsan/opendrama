# 仙侠人物服饰风格词库

## 收录原则

- 只收身份、服饰结构、色彩、发型、配饰和道具锚点，不复制原文提示词。
- 这类模板优先用于角色阵营和职业区分，例如仙门、妖族、佛修、女将、毒医。
- 强身份元素必须由剧情支撑，例如狐耳狐尾、戒疤、药瓶、战靴、八卦星象纹。
- 生成角色定稿时优先保持“发型轮廓 + 主色 + 标志配饰”稳定，不把所有华丽细节一次性堆满。
- 参考图带水印，只用于风格分析，不进入项目素材。

- 模板包含男修、佛修、女将、少女、尊者、师姐、毒医和狐族贵公子，比单一“绝美女主”更适合做群像角色卡。
- 每个角色有正面、侧面、背面和头像视角，适合提炼为角色定稿图和三视图要求。

限制：
- 第 2 页和第 3 页为同一组“孤尊”重复内容；第 11 页基本为空页。
- 文章偏仙侠概念设计，不是严格朝代服制，不能直接当历史服装依据。
- 部分词如“狐耳狐尾、佛门弟子、毒医仙子”身份很强，不能随意套给普通人类角色。

## 角色组合建议

仙门群像：
- 男主可用青玄或玄宸，女主可用月白或赤霄，师门长辈可用玄宸，外门配角用更朴素的青灰布袍。
- 如果同场出现青玄和月白，青玄强调玉冠、青黛外袍、仙鹤纹；月白强调冰蓝薄纱、梅花暗纹、清冷师姐感。

妖族线：
- 孤尊适合作为妖族高位角色，不适合作为普通“帅男主”模板。
- 狐族身份可以保留狐耳、狐尾、金瞳三者中的一到两个，避免每张图都过度动物化。

战斗线：
- 赤霄适合正面冲突、持剑、奔跑、回身防守、战场风沙等镜头。
- 服饰要保留短靴、护腕、腰带、武器位置，视频提示词里不要突然变成长裙礼服。

药毒线：
- 毒医仙子适合药房、竹林、暗室、山谷、采药、施针、调药等场景。
- 可用药瓶、药囊、草药发饰做识别点，不必每个镜头都出现所有道具。

## OpenDrama 用法

- 角色定稿：按 `species/faction/role`、`outfit_palette`、`signature_accessory` 三个字段保存，例如“狐族 / 琥珀金白 / 狐尾和火焰纹”。
- 分镜：先确定角色身份，再决定动作；身份强的道具必须连续，例如赤霄的剑、毒医的药囊、玄宸的太极玉佩。
- H3 视频：首尾帧只允许袖摆、发丝、披帛、云雾、药囊轻晃等小幅运动；不要让服装颜色、发冠、武器或种族特征在视频中变化。
- 群像生成：每个主要角色至少区分一个大轮廓元素，例如狐尾、光头、战靴、高冠、双丸子头、药囊，而不是只区分颜色。

## 风险

- 这篇文章适合补“仙侠角色差异化”，不适合作为所有古风角色的默认审美。
- “桃夭”这类甜系少女模板容易低龄化，恋爱线使用时要明确年轻成年。
- “月白”和现有清冷女主模板有重叠，使用时应根据剧情选择其中一个作为主模板，避免同剧多位角色撞型。
