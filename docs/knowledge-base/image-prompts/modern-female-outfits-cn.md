# 现代女主服装风格词库

## 收录原则

- 目标是给现代女主按剧情场景换装，不替代角色脸部、发型和气质设定。
- 每套服装至少明确 4 个锚点：场景、上装、下装或裙型、材质和色彩。
- 服装风格必须服从人物身份、职业、阶层和镜头场景，不能只按“好看”套用。
- 参考图有水印，只用于理解服装结构，不进入项目素材。

```text
no unrelated outfit, no costume mixed with wrong era,

no same outfit across all scenes, no impractical clothing for action scenes
```

## OpenDrama 用法

- 角色 bible：每个现代女主可以保存 2 到 4 套服装版本，例如日常通勤、职场、约会、宴会。
- 分镜换装：换服装必须由剧情场景触发，不要在连续镜头里无理由换装。
- 角色一致性：换装时保持脸部、发型核心轮廓和主要配饰稳定，只改变服装和场景道具。
- H3 视频：视频提示词只描述当前镜头服装，不要把 18 种风格混写到一个镜头里。

## 风险

- 这篇是服装风格库，不是人物设定库；不能用服装替代人物性格、职业和关系。
- 总览中部分风格偏时尚写真，直接套到剧情分镜会显得不合理。
- 服装词过多会让模型忽略人物一致性，运行时应只选一套主服装和少量材质细节。
