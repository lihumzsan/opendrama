# 现代女主面部气质差异化词库

## 收录原则

- 目标是减少模板脸，不是堆叠更多“美女”标签。
- 每个角色至少明确 3 个差异维度：脸部轮廓、眼神表情、发型长度或质感、妆感浓淡、影调或场景。
- 风格词必须服务人物身份和剧情，不按“99%人想要”这类营销话术直接使用。
- 参考图有水印，只能用于理解风格，不进入项目素材。

## 来源评估

来源：`告别模板脸！15组专属提示词，解锁99%人都想要的AI女主角`，公众号文章 PDF，2026-08-07 本地导出。

结论：改写后收录为面部气质差异化补充库。

可用点：
- 覆盖清冷、甜美、知性、森系、港风、复古、职场、机车、法式、运动等现代写真风格。
- 适合给已有现代女主原型增加脸部和气质差异，避免所有角色都是同一种网红脸。
- 对角色封面、头像、宣传海报和人物设定板有帮助。

限制：
- 这篇不是严格的“脸型库”，更多是现代女主写真风格库。
- 多数示例仍偏高颜值写真，直接套用仍可能生成同质化脸。
- 不能替代角色 bible；必须结合人物年龄、职业、阶层、性格和剧情状态。

## 推荐组合规则

- 一个角色只选 1 个主风格，再选 1 个辅助差异点。
- 不要同时写“清冷、甜美、港风、森系、御姐、初恋感”，会互相抵消。
- 同剧角色差异示例：女主知性文艺，闺蜜元气校园，姐姐职场知性，反派港风冷艳。
- 角色定稿优先写稳定特征：脸部轮廓、发型、眼神、妆感；封面海报再加入影调和场景。
- 五类人设组合只能作为角色功能入口，最终仍要落到年龄、职业、阶层、关系和剧情状态，不能只写“甜妹”“御姐”“反派”。

## 脸型使用规则

- 先定人物功能，再选脸型方向：复仇线看骨相和眼神，甜宠线看亲和度，职场线看轮廓清晰度，治愈线看柔和度。
- 一个角色只固定 2 到 3 个脸部锚点，例如 `偏长脸型 + 下颌线干净 + 冷静眼神`，不要把五官清单堆满。
- 同剧女主、女二、反派和闺蜜至少区分两个锚点：脸型轮廓、眼神、妆感、发型、影调。
- “病娇、钓系、狐系、厌世、反差”等词只作为剧情功能入口，运行时改成具体表情、妆造和行为状态。
- 不能把脸型当作演员评价标准，也不能说某种脸只能演某类剧；知识库只服务虚构角色生成和视觉一致性。

脸型负面约束：

```text
no same face across female characters, no generic influencer face,
no over-sharpened V-line, no plastic-surgery look, no childish sexualization,
no disease romanticization, no ethnicity stereotype, no evil-by-face stereotype,
no conflicting face-shape labels, no excessive beauty filter
```

## OpenDrama 用法

- 角色识别：在角色视觉描述里固定 `face_shape`、`gaze`、`hair`、`makeup` 四类锚点。
- 角色区分：同一部剧多个女性角色至少改变两个锚点，例如发型和妆感，不能只换衣服。
- 封面图：可以加入港风、森系、法式、复古等影调；角色定稿图不宜过度依赖滤镜。
- H3 视频：面部气质只作为一致性约束，不在视频提示词里反复更换妆发和影调。

## 风险

- 这篇的“告别模板脸”主要靠风格包装，不能自动解决脸部一致性。
- 真正避免撞脸，需要在角色 bible 中记录稳定面部锚点，并在所有图片和视频任务里复用。
- 港风、法式、纯欲、运动等风格容易被模型放大成性感写真，应由剧情场景决定是否使用。
